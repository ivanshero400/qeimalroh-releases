# قِيَمُ الرُّوح

**حاسب نفسك قبل أن تُحاسَب.**

تطبيق عربي مجاني لنظام Android للمحاسبة قبل النوم، وتجديد التوبة، وخطة إصلاح الغد. يعمل على جهازك دون حساب أو إنترنت.

[تنزيل APK لنظام Android](https://github.com/ivanshero400/qeimalroh-releases/releases/latest/download/qeimalroh-1.0.0.apk) · [بيان الخصوصية](privacy.md)

تحتاج إلى Android 7.0 أو أحدث. افتح ملف APK على هاتفك واتبع تعليمات Android. يتوفر ملف AAB ضمن ملفات الإصدار للتوزيع، ويتوفر ملف SHA256 للتحقق من سلامة التنزيل.

تضم المكتبة ٢٢ موعظة و٧١ نصًا بمصادرها و٣١ بطاقة أذكار. تُحفظ خططك وحقوقك والمفضلة محليًا في تخزين مشفّر. تحفظ المحاسبة تاريخ الجلسة فقط إذا اخترت ذلك.
